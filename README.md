# PluginUnityMusicPlayer

A lightweight Unity plugin for playing music on Android using a native `.aar` library.

## Build

After building the Android module, the generated `.aar` file will be located at:

app/build/outputs/aar/

## Installation

1. Rename the generated `.aar` file if desired.
2. Copy it into your Unity project under:

Assets/Plugins/Android/

3. Unity will automatically include it in the Android build.

## Requirements

- Unity (Android platform enabled)
- Android Gradle build system
